# MySQL 面试知识库

这组文档面向 Java 后端开发者：能解释数据库行为，也能回答“业务里怎么做、为什么这样做、有什么代价”。默认讨论 **MySQL 8.0、InnoDB**；版本差异会单独说明。

## 怎么背

每个问题先记住“面试回答”，再看业务追问和易错点。回答时按照 **结论 → 原因 → 业务做法 → 边界** 展开，不用把整篇原样复述。

第一次阅读按目录顺序进行。时间有限时，优先掌握索引设计、慢 SQL、事务、MVCC、锁和并发一致性；面试前用 [高频速记](./12-review) 自测，再回到对应正文补充解释。

## 内容范围

内容来自已有的《MySQL-基础篇》《MySQL-进阶篇》《MySQL-运维篇》，按面试问题重新组织。保留支撑业务判断的必要原理，略去安装下载、工具教程、环境搭建、完整项目案例、备份部署、MyCat 配置和存储过程语法训练。

短 SQL 只用于说明一个业务判断，不需要准备项目或执行练习。SQL 中的参数采用 JDBC `?` 占位符；表、字段仅表达业务含义，不构成完整建表脚本。

第 09 篇的业务方案以及部分 Java 映射、版本边界属于面试补充，不是 PDF 原文。各篇末尾列出对应 PDF 页码和必要的官方核对链接；[资料取舍与校正说明](./13-sources) 记录原资料中需要纠正的表述。

背诵能帮助建立回答框架；业务追问仍需要理解条件与取舍，不能把有前提的结论当成通用规则。
