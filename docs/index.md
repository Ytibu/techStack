# Java 后端知识库

面向已有开发基础、希望系统复习的 Java 后端学习者。围绕常用技术栈整理核心概念、运行原理与实现方式，把分散的学习资料组织成便于阅读、查阅和回顾的知识体系。

内容以已有资料为基础，保留知识点之间的顺序与联系，简化冗长讲解和重复操作，配合必要的命令、代码与对比说明，帮助理解机制及其适用场景。

## 知识体系

点击专题名称，进入对应的目录首页。

| 专题 | 内容 |
| --- | --- |
| <span style="white-space: nowrap">[MySQL](/knowledge/mysql/)（[业务型](/mysql/)）</span> | 基础、索引、事务、锁、InnoDB 与运维机制；业务型按场景问题组织，适合方案查阅与面试复习 |
| [Redis](/redis/) | 分布式缓存、多级缓存、最佳实践、底层原理与基础命令 |
| [RabbitMQ](/knowledge/rabbitmq/) | 预留专题，后续整理消息可靠性、消费、重试与积压等内容 |
| [Spring Boot](/knowledge/springboot/) | 预留专题，后续整理自动配置、依赖注入、AOP 与事务等内容 |

## 阅读方式

系统复习时，从专题目录按章节阅读；针对具体问题查阅时，使用顶部搜索定位知识点。MySQL 默认进入知识体系，可点击旁边的“业务型”切换阅读入口；Redis 使用统一的一套内容。
