## 关键事实校正

资料使用 MySQL 8.0.26 的课程语境。正文默认讨论 MySQL 8.0 / InnoDB，不沿用“最新版本”或跨版本固定参数的说法。

| 原资料中的简化 | 本文处理与核对依据 |
| --- | --- |
| MySQL 8.0 服务层仍有旧查询缓存 | 区分已移除的查询缓存与 Buffer Pool；[8.0 功能变化](https://dev.mysql.com/doc/refman/8.0/en/mysql-nutshell.html) |
| VARCHAR 声明长度按固定 bytes 理解 | 区分字符上限、实际字节与行限制；[字符类型](https://dev.mysql.com/doc/refman/8.0/en/char.html) |
| 无主键就直接生成隐藏行 ID | 还要检查合适的全非空唯一索引；[聚簇索引](https://dev.mysql.com/doc/refman/8.0/en/innodb-index-types.html) |
| 缺最左列就全部失效，范围后列都无用 | 区分定位、过滤、覆盖及特殊访问；[范围优化](https://dev.mysql.com/doc/refman/8.0/en/range-optimization.html) |
| >= 比 > 通用地恢复全部索引列 | 根据区间与语义判断，不从个例推导固定规则；[多列区间](https://dev.mysql.com/doc/refman/8.0/en/range-optimization.html#range-access-multi-part) |
| Using index 等于按索引排序，Using index condition 仅表示回表 | 分别解释覆盖、下推与排序；[EXPLAIN 输出](https://dev.mysql.com/doc/refman/8.0/en/explain-output.html) |
| 没有合适索引导致行锁升级表锁 | 解释扫描与加锁范围扩大；[InnoDB 加锁](https://dev.mysql.com/doc/refman/8.0/en/innodb-locks-set.html) |
| 视图 CHECK OPTION 对删除也执行相同条件检查 | 按插入、更新及可更新性解释；[视图检查选项](https://dev.mysql.com/doc/refman/8.0/en/view-check-option.html) |
| Log Buffer 笼统保存 redo 和全部 undo | 区分 redo 缓冲与 undo 的页和表空间组织；[内存结构](https://dev.mysql.com/doc/refman/8.0/en/innodb-in-memory-structures.html) |
| ReadView 上界使用严格大于 | 区分下一待分配 ID 的含等号边界；[ReadView 源码](https://github.com/mysql/mysql-server/blob/mysql-8.0.26/storage/innobase/include/read0types.h) |
| 仅 redo 和 undo 就自动保证业务一致性 | 同时解释约束、隔离和正确修改逻辑；[InnoDB ACID](https://dev.mysql.com/doc/refman/8.0/en/mysql-acid.html) |
